# 验证范围

扩展版本 0.5.0。

自动化测试使用实际加载扩展的隔离 Chromium 配置，在路由拦截后的本地演示页运行，不使用真实 AI 账号，也不发送真实平台消息。

测试覆盖：自动添加、IndexedDB 保存、备份导入、去重、文字 + 表情、纯图发送、发送后收起、1 张与多个收藏时面板尺寸不变、15 张分页、上传期间草稿改变时停止。

本聊天开发过程中另已验证旧收藏迁移、超过原约 7 MB 容量的存储、备份导出 / 恢复和 GIF 字节保留。公开测试脚本只展示不依赖私人文件的复现路径。

真实使用：ChatGPT 有作者试用反馈；Muse 目前按观察到的网页结构实现基础适配，尚未建立完整的真实站点回归。网页变更、上传限制、动图播放和模型语境理解不能由本地测试保证。
