# 隐私与数据流

## 本地数据

用户主动选择的原图、静态缩略图、文件内容哈希、名称、搜索备注、收藏状态、最近使用时间及分组保存在扩展自身来源的 IndexedDB。
旧版 chrome.storage.local 收藏会迁移，原旧数据保留作恢复副本，不反复迁移。

选择文件只授予所选文件的访问能力，不自动扫描磁盘。导入时无网络上传；源码没有遥测端点。

## 发送

点击某张表情时，扩展读取该图，通过网页原有文件输入加入附件，并在检查草稿未变化后点击网页发送按钮。输入框已有文字时将与图片一起提交；已有其他附件时停止。
名称、分组和备注不加入聊天文本。没有额外提示词、模型 API、Cookie 抓取或账号接口调用。

扩展使用 DOM 检查当前输入区与附件状态，可能接触其中已有的草稿；不把它们发送到开发者服务器，不抓取历史对话。当前 AI 平台收到附件后的处理由其自身政策决定。

## 权限、备份与卸载

Manifest V3，仅申请 storage；内容脚本限定 chatgpt.com / muse.ai。
JSON 备份含完整图片与本地管理信息，请自行保管。卸载或更换扩展 ID 会导致本地库不可用或被清除，提前备份。

## 公开素材

仓库只包含源码、图标和原创演示图片。截图在本地模拟页面生成，不含使用者的真实聊天或私人收藏。
