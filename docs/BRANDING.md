# 企鹅形象

0.5.1 使用内置 imagegen 生成的原创企鹅头像，随后仅进行透明边界裁剪和图标尺寸缩放。它用于扩展图标、网页按钮和 README 横幅，不是任何既有角色的官方授权形象。

素材：`images/penguin.png`；扩展提供 16、32、48、128 像素 PNG 图标。横幅文字由网页排版后截图生成，以保证中文准确。
